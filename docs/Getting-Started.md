# Getting Started

1. Run the npm installer or clone and run `scripts/install.mjs`.
2. Replace placeholders in `playbook/environment-profile.yml`.
3. Restart OpenCode.
4. Run `/verify` on a small checklist with a planted defect.
5. Run `/feature-plan`, plan approval, `/implement`, `/verify`, acceptance and release readiness.

For a live demonstration, use `Greenfield-Case-Study.md` or `Brownfield-Case-Study.md`.
